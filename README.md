# NutriFit DZ

منصة جزائرية لوجبات الرياضيين: تحسب احتياجك، تبني وجباتك بالغرام، وتوصَّل غدًا.
نسخة المرحلة 1: تطبيق ويب ثابت بلا أدوات بناء (HTML + JS عادي). يعمل بفتح `index.html` أو من أي خادم ثابت.

```

├─ index.html              الهيكل + ترتيب تحميل السكربتات
├─ README.md
├─ css/

├─ js/                     سكربتات عادية، الرقم = ترتيب التحميل
```

## ما هو مكتوب بالفعل في الكود

- RMR: Mifflin-St Jeor (F)، وKatch-McArdle عند LBM موثوق ≥ 70% (العتبة C).
- PAL: أربعة مستويات، كل قيمة افتراضية داخل نطاق FAO/WHO/UNU 2004 (النطاق R، القيمة O).
- الهدف: ±25% كحد أقصى؛ عجز أكبر من 20% يحتاج تأكيدًا؛ لا يقل الهدف عن RMR.
- البروتين ضمن نطاق ISSN 2017، والدهون 25% افتراضيًا (AMDR 20-35)، والكارب = الباقي، والألياف ≥ 25 غ.
- الكارب السالب يُرجع `MACROS_EXCEED_TARGET` مع تفصيله ولا يُقرَّب إلى صفر.
- المكمل: نصح فقط، السقف 50% من بروتين اليوم (قرار منصة، تصنيف C).
- الحساسيات: الأربع عشرة الأوروبية، والطعام المطابق يُحجب ولا يُتجاوز.
- المال: أعداد صحيحة بالسنتيم (لا Float)، والتوقيت UTC+1 ثابت للجزائر.
- الطلب Snapshot لا يتغير لو تغيرت الأغذية لاحقًا. الدفع عند الاستلام.

## ⚠️ قبل أي إطلاق فعلي

1. **الأغذية:** `js/03-foods.js` قيمه تجريبية من غير مصدر. استبدلها بسجلات USDA FoodData Central / Ciqual / الملصق الرسمي مع `sourceId` و`sourceRecordId` حقيقيين، وراجع الحساسيات، ثم غيّر `FOOD_DATA.verified` إلى `true`. طالما هي `false` يظهر تحذير أحمر وتُحفظ الطلبات بحالة `DRAFT_DEV`.
2. **الأسعار:** `NF.PRICING.pricePerKgCentimes` فارغ، وكذلك `deliveryFeeCentimes`. يحددها المشرف. ساعة الإغلاق 20:00 افتراض (C).
3. **معاملات الطهي:** لا قيم فيها عمدًا. `kitchenQuantities` يتطلب معاملًا من جدول USDA الرسمي.
4. **الخلفية:** لا قاعدة بيانات ولا حسابات بعد؛ الحالة والطلبات في `localStorage`. المرحلة التالية: PostgreSQL + Prisma + لوحة المطبخ.
5. **البيانات الشخصية:** الوزن والعمر والحساسيات بيانات شخصية؛ راجع القانون 18-07 وبند التصريح لدى ANPDP قبل جمعها على خادم.
6. **المراجع:** KATCH وATWATER و7700 kcal/kg عليها `TODO_VERIFY` ولم تُؤكد بعد.

## قواعد التعديل

- ملف JS جديد: أضفه في `index.html` بالترتيب، وشغّل الاختبارين.
- لا تضع منطقًا علميًا داخل `05-ui.js`؛ مكانه `02-engine.js` ويُختبر في `engine.test.js`.
- التقريب للعرض فقط (`r0`/`r1` في الواجهة)، والقيم المحسوبة تبقى بدقتها الكاملة.
